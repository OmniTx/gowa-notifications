# Contributing to GOWA WhatsApp Notifications

Thank you for your interest in contributing! This project is open-source under the GPL-2.0 license.

## How to Contribute
1. **Fork the Repository**: Click the **Fork** button on GitHub.
2. **Create a Feature Branch**: `git checkout -b feature/your-feature-name`
3. **Commit Your Changes**: `git commit -m "Add new feature"`
4. **Push to Your Branch**: `git push origin feature/your-feature-name`
5. **Open a Pull Request**: Submit a PR to the `main` branch with a description of your changes.

## Guidelines
- Follow standard WordPress PHP coding standards.
- Ensure all sensitive credentials remain configurable via dashboard settings.
- Test your changes against the latest version of WooCommerce and WordPress.
