WordPress.org Plugin Directory Assets
=====================================
Drop your exported Photoshop images directly into this folder:

1. Icons:
   - icon-128x128.png (128x128 px)
   - icon-256x256.png (256x256 px - Retina)

2. Banners:
   - banner-772x250.png (772x250 px)
   - banner-1544x500.png (1544x500 px - Retina)

3. Screenshots (Optional):
   - screenshot-1.png (1280x720 px)
   - screenshot-2.png (1280x720 px)

When you run the "Deploy to WordPress.org" workflow, these files will be uploaded
directly to WordPress.org SVN /assets/ and displayed on your public plugin page.
They will NOT be included in the user plugin download.
